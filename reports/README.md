# Report Generation Service

Module for generating official Legal Metrology Compliance Inspection Reports in PDF format using ReportLab.

## Setup & Running

1. **Install dependencies**:
   ```bash
   pip install -r reports/requirements.txt
   ```

2. **Generate Sample PDF**:
   ```bash
   python reports/report_generator.py
   ```
   This will generate a sample `test_inspection_report.pdf` in the workspace directory.
